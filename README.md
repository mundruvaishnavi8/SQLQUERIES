# SQL Practice Queries

## 📖 Project Overview
This repository contains SQL queries written while practicing the BikeStores sample database. It covers beginner to Intermediate SQL concepts for data analysis.

## 🛠️ Tools Used
- SQL Server
- SQL Server Management Studio (SSMS)

## 📚 SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
